## How to go live (one-time setup, ~2 min)
1. Make the repo **public** (required for free GitHub Pages):
   Settings → Danger Zone → Change visibility → Make public.
2. Enable Pages: Settings → Pages → Deploy from a branch →
   branch `arena/01a05460-my-first-project` → `/ (root)` → Save.

After that the site is always live and updates automatically on every push —
no Netlify needed.

## MT5 EA install (one-time)
1. Download `AI_Momentum_Trend.mq5`.
2. Copy into `MetaTrader 5 → MQL5 → Experts`.
3. MT5 → Navigator → Refresh → drag EA onto chart → enable Algo Trading.
4. Auto-trade is OFF by default (signals + arrows only). Read `backtest.html`
   before enabling it.
